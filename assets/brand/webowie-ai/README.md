# webOwie AI — Subbrand Logo System

`webOwie AI` is a controlled subbrand of the webOwie visual system. It is designed for AI gateway, local-model orchestration, agent infrastructure, inference routing, automation and related product surfaces.

## Parent-brand anchors

The subbrand intentionally preserves the established webOwie identity:

- geometric hexagonal network mark
- near-black `#050505` background
- primary foreground `#F5F5F5`
- cyan accent `#55DCE8`
- legacy-compatible cyan `#3DD9E8`
- secondary grey `#C8CDD2`
- structural line grey `#2B3138`
- system/Inter-style sans-serif typography
- restrained, high-contrast, infrastructure-oriented composition

The parent symbol itself is not replaced or redrawn. Subbrand differentiation is introduced through the separate cyan `AI` module.

## Logo hierarchy

1. **Primary horizontal lockup** — default for web UI, documentation, headers and product branding.
2. **Stacked lockup** — square or portrait placements.
3. **Application icon** — OmniRoute/PWA/app icon and launcher contexts.
4. **Favicon** — simplified mark for very small sizes.
5. **Monochrome variants** — engraving, terminal, single-colour print and constrained environments.
6. **GitHub social preview** — repository/social preview composition.

## Clear space

Use a minimum clear space equal to the diameter of the central cyan node around the complete lockup. For product headers and social graphics, prefer at least 2× this amount.

## Minimum sizes

- horizontal lockup: 220 px CSS width minimum
- stacked lockup: 180 px width minimum
- app icon: 48 px minimum
- favicon: 16 px minimum

Below these sizes, use `favicon.svg` rather than the full lockup.

## Colour rules

### Dark surfaces

Use:

- background: `#050505`
- mark/wordmark: `#F5F5F5`
- AI module: `#55DCE8`

### Light surfaces

Use:

- mark/wordmark: `#050505`
- AI accent: `#3DD9E8`
- dark cyan text where contrast requires it: `#0F7580`

Do not introduce unrelated gradients or additional product colours into the logo itself.

## Subbrand rule

`AI` must remain visually subordinate to `webOwie`. It is a product-domain identifier, not a replacement master brand. The `AI` module may be removed when only the parent brand is intended; the `webOwie` parent mark must not be replaced by an unrelated AI glyph.

## Do not

- recolour the parent symbol with arbitrary colours
- stretch, skew or rotate the lockup
- merge the letters `AI` into the parent hexagon
- use glow, bevel, chrome or 3D effects in the canonical logo
- reduce contrast below accessible UI levels
- use the full horizontal lockup as a favicon
- change the cyan centre node to another semantic colour

## Product naming

Preferred forms:

- `webOwie AI`
- `webOwie AI Gateway`
- `webOwie AI · OmniRoute`

Avoid all-caps `WEBOWIE` as the master wordmark except where typography constraints require it.
